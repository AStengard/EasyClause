    Architecture & Privacy Guide

    How EasyClause Works

    EasyClause is built with a privacy-first, client-side architecture. Whether running 100% offline or using live generative AI, your contracts are never retained on an intermediary server. Public demo applications operate strictly stateless for privacy during evaluation, with enterprise integration available for persistent document management.

    100% Offline

    Instant Mode & Register

    Designed for users who want to safely store, search, and manage contracts without any cloud dependencies, external tokens, or internet transmission.

    In-Browser PDF Extraction: Uses Mozilla's PDF.js library to convert PDFs to clean searchable text directly in your browser.
    Stateless Testing & Flexible Storage: Public demos operate strictly stateless without saving data across sessions for privacy. For enterprise deployments, EasyClause readily integrates with platforms like Microsoft SharePoint & OneDrive.
    Pre-Scanned Demo Library: Includes 4 pre-computed real-world commercial contracts to demonstrate risk analysis and clause breakdowns offline.
    Air-Gapped Operation: Works completely disconnected from the internet. No network requests are dispatched.
    BYOK Architecture

    Live AI Integration

    Connect directly to premier AI foundation models (Gemini, OpenAI, Claude) using your own API key for real-time legal risk assessments.

    Direct Browser-to-Model API: Requests are dispatched directly via HTTPS from your browser to Google, OpenAI, or Anthropic.
    BYOK Key Storage: Your API key is saved solely in your local browser storage. It is never logged or transmitted to any third party.
    Point-of-View (POV) Legal Framing: By entering your organization's name, the system prompt instructs the AI to evaluate clauses strictly from your strategic viewpoint.
    Verbatim Proof Extraction: Each categorized clause pairs AI insights with the exact, unedited original text as evidentiary proof.

    Frequently Asked Questions

    How is data stored between sessions, and what integrations are available?

    The public demo applications intentionally do not store or persist data between sessions (they operate strictly stateless for privacy and security during testing). However, for enterprise deployment, the tools can readily integrate with existing document management platforms (such as Microsoft SharePoint or OneDrive) to securely save the data between sessions.

    Are my contracts used to train public AI models?

    No. Under standard commercial API terms (Google Cloud Vertex/Studio, OpenAI API, and Anthropic API), data submitted through developer API keys is not used to train foundation models. This is fundamentally different from free consumer chat interfaces.

    Can I save an agreement offline now and scan it with AI later?

    Yes! You can save agreements in Instant Mode completely offline. Whenever you wish to run a live AI scan, open the agreement from your register and click the "Scan with Live AI" button to run a deep analysis with your API key.

    Where are my API keys saved in Live AI Mode?

    When entering your own API key in Live AI Mode, the key is saved solely within your browser’s local client storage (window.localStorage). It is never logged, forwarded to intermediate servers, or accessible to third parties, and you can clear or reset it at any time.
